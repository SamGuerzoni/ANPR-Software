ℹ️ About GuardView ANPR System

The GuardView ANPR system is designed for real-time license plate detection and logging using RTSP camera feeds. It aims to provide reliable and user-friendly surveillance analytics with high performance and accuracy.

  • 📷 Multi-camera RTSP live stream preview
  • 🔎 Real-time ANPR logging with number plate, image, and timestamp
  • 📊 Reports with time-based filtering and Excel/PDF export
  • 🛡️ License-protected software (days left shown on dashboard)
  • ⚙️ Editable camera settings and archive retention policies
